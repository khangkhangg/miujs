# Contributing to MiuJS

Thanks for helping. Read [AGENTS.md](AGENTS.md) first: it has the layout, commands and house
rules (test-first, erasable TypeScript, web standards only, `MiuError` with a fix).

## Workflow

1. Write a failing test in the package's `test/` folder and watch it fail.
2. Write the smallest change that makes it pass.
3. Run `bun test` and `bun run typecheck` before opening a pull request.
